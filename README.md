# Astrology landing concept

Концепция первого экрана продающего сайта для женщины-астролога. Экран построен вокруг личности эксперта, понятного результата консультации и безопасного первого шага за 99 ₽.

## Что реализовано

- адаптивный первый экран для desktop, tablet и mobile;
- статусная тёплая визуальная система без эзотерических клише;
- блоки доверия без выдуманных числовых показателей;
- модальное окно заявки;
- сценарий «как проходит звонок»;
- демонстрационное состояние после отправки формы;
- фиксированная CTA-кнопка на мобильных устройствах;
- базовая клавиатурная доступность и поддержка `prefers-reduced-motion`.

## Просмотр

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
```

## Перед запуском

Нужно заменить демонстрационные имя и фотографию на материалы эксперта, подставить подтверждённые цифры доверия, подключить оплату, CRM/Telegram и юридические документы.
